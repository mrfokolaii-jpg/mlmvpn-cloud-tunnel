# تونل من — آزمایش VPN با GitHub Actions

این مخزن در ابتدا فقط عامل سمت سرور MLMVPN را داشت. اکنون سورس یک **اپ اندروید آزمایشی** هم در `android/` قرار دارد: ورود از صفحهٔ اصلی GitHub، انتخاب کشور، دکمهٔ شروع/قطع و تلاش برای جایگزین‌کردن خودکار نشست پیش از پایان آن.

> **مهم: نامحدود واقعی نیست.** هر job روی رانرهای میزبانی‌شدهٔ GitHub حداکثر ۶ ساعت اجرا می‌شود. این پروژه هر نشست را حدود ۳۳۵ دقیقه نگه می‌دارد و قبل از پایان برای نشست بعدی تلاش می‌کند، اما صف، سهمیه، هزینه، محدودیت شبکه یا سیستم‌عامل می‌توانند اتصال را قطع کنند. دو نشست ممکن است هنگام تعویض برای مدتی هم‌زمان اجرا شوند و هر دو از سهمیه استفاده کنند. در تصویر ارائه‌شده، برنامهٔ قبلی حساب را `Allowance spent` نشان می‌داد؛ وضعیت واقعی را در بخش Billing / Actions گیت‌هاب بررسی کنید.
>
> GitHub Actions برای توسعه و آزمایش است. استفادهٔ دائمی از رانرهای GitHub به‌عنوان VPN ممکن است با [شرایط GitHub Actions](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#actions) ناسازگار باشد و به محدودیت یا تعلیق حساب منجر شود. برای سرویس طولانی‌مدت، سرور مستقل مناسب‌تر است. این کد فقط برای آزمایش ارائه شده و امنیت و پایداری آن روی دستگاه واقعی هنوز تأیید نشده است.

## ساخت APK

سورس اندروید نیازمند **Android SDK 35، JDK 17 و Gradle 8.9** است. کتابخانه‌های بومی از نسخه‌های مشخص‌شدهٔ libXray و hev-socks5-tunnel دریافت می‌شوند و SHA-256 آن‌ها پیش از استفاده بررسی می‌شود؛ فایل‌های باینری در مخزن قرار نمی‌گیرند.

### با GitHub Actions

1. تغییرات این شاخه باید در شاخهٔ پیش‌فرض مخزن قرار بگیرند؛ هر دو workflow جدید و فایل‌های `agent/` باید در آن شاخه موجود باشند.
2. در GitHub به **Actions → Build Android app → Run workflow** بروید. پس از موفقیت، artifact با نام `cloudpath-vpn-debug` حاوی `app-debug.apk` است. نصب APK آزمایشی ممکن است نیازمند اجازهٔ نصب از منبع ناشناس در اندروید باشد.
3. این APK با کلید debug امضا می‌شود و برای انتشار عمومی مناسب نیست. اجرای build هم از سهمیهٔ Actions حساب استفاده می‌کند. صرف وجود workflow به معنی ساخته‌شدن APK نیست.

### روی کامپیوتر توسعه

```bash
cd android
./scripts/fetch-native.sh
gradle --no-daemon testDebugUnitTest assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## ورود اصلی GitHub

اپ از **OAuth Device Flow** و مرورگر استفاده می‌کند؛ گذرواژه یا Client Secret در اپ وارد نمی‌شود و نیازی به فرستادن هیچ کد یا توکنی در چت نیست.

1. در تنظیمات GitHub یک **OAuth App** بسازید: نام دلخواه و برای Homepage و Callback یک URL معتبر مانند `https://github.com` وارد کنید. سپس در تنظیمات همان OAuth App گزینهٔ **Enable Device Flow** را فعال کنید.
2. فقط **Client ID عمومی** آن اپ را در برنامهٔ اندروید وارد کنید. Client Secret را در اپ یا چت وارد نکنید.
3. کدی را که روی گوشی ظاهر می‌شود فقط در `github.com/login/device` وارد کرده و درخواست دسترسی را تأیید کنید. اپ برای خواندن مخزن خصوصی و کنترل Actions، مجوز `repo` می‌خواهد؛ این مجوز به همهٔ مخازن خصوصی حساب دسترسی دارد، نه فقط به این مخزن. می‌توانید بعداً مجوز OAuth App را از تنظیمات GitHub لغو کنید.
4. مخزن پیش‌فرض به‌شکل `نام‌کاربری/mlmvpn-cloud-tunnel` است و از صفحهٔ حساب قابل تغییر است. workflow به نام `.github/workflows/github-vpn-session.yml` باید روی شاخهٔ پیش‌فرض موجود باشد. در صورت منع دسترسی نوشتن `GITHUB_TOKEN`، تنظیمات **Actions → General → Workflow permissions** مخزن نیز باید نوشتن محتوا را مجاز کند.

توکن OAuth در Android Keystore رمزگذاری و فقط در ذخیره‌سازی خصوصی همان دستگاه نگهداری می‌شود. نسخهٔ پشتیبان اندروید برای اپ غیرفعال است. خروج از حساب داخل اپ فقط اطلاعات محلی را پاک می‌کند؛ لغو مجوز در خود GitHub جداگانه است.

## رفتار اتصال و محدودیت‌ها

- گزینهٔ «حداکثر سرعت» از آدرس خود رانر استفاده می‌کند. کشور انتخابی فقط وقتی فعال می‌شود که خروجی VPN Gate برای همان کشور آماده باشد و سرویس مکان‌یابی، همان کشور را گزارش دهد. فهرست کشورها به معنی تضمین وجود سرور نیست؛ ممکن است کشور انتخاب‌شده در دسترس نباشد یا مکان‌یابی اشتباه باشد. هنگام اتصال برای تغییر کشور ابتدا قطع کنید.
- برای جلوگیری از سقوط بی‌صدا به خروجی رانر، اپ برای کشور انتخاب‌شده فقط VPN Gate را درخواست می‌کند؛ مسیر Psiphon موجود در عامل قدیمی برای این اپ استفاده نمی‌شود چون UDP آن از خود رانر خارج می‌شود. با این حال، تشخیص کشور و جلوگیری از نشت در همهٔ شرایط تضمین‌شده نیست.
- پس از درخواست Start، آماده‌شدن نشست و خروجی ممکن است چند دقیقه طول بکشد. اپ پیش از نشان‌دادن اتصال، مسیر رمزگذاری‌شدهٔ وضعیت را از داخل پروکسی بررسی می‌کند؛ این بررسی تضمین نمی‌کند که همهٔ سایت‌ها یا خروجی انتخابی همیشه در دسترس باشند.
- Stop اتصال گوشی را قطع می‌کند و تلاش می‌کند **فقط runهای همین اپ** را در GitHub لغو کند. اگر اینترنت یا GitHub در دسترس نباشد، قطع‌شدن run سمت GitHub تضمین نمی‌شود؛ شناسه برای تلاش مجدد نگهداری می‌شود و پیام هشدار نمایش داده می‌شود. در صورت لزوم run را در بخش Actions به‌صورت دستی لغو کنید.
- وقتی VPN قطع می‌شود، اندروید ممکن است اینترنت را مستقیم برقرار کند. در صورت نیاز به جلوگیری از عبور مستقیم، در تنظیمات سیستم اندروید «Always-on VPN» و «Block connections without VPN» را بررسی کنید؛ رفتار آن بسته به دستگاه متفاوت است.
- دسترسی به رانر از رله‌های عمومی یا Cloudflare Quick Tunnel استفاده می‌کند؛ این سرویس‌های ثالث ممکن است در شبکهٔ شما قطع، فیلتر یا کند باشند. نسخهٔ اندروید از VMess AEAD داخل WebSocket استفاده می‌کند تا محتوای جریان برای رلهٔ خاتمه‌دهندهٔ TLS آشکار نباشد؛ VMess محرمانگی پیشرو (forward secrecy) ندارد و رله همچنان IP، زمان و حجم اتصال را می‌بیند. این پروژه حسابرسی امنیتی یا آزمون کامل روی گوشی واقعی نشده است.
- سیستم اندروید ممکن است سرویس پس‌زمینه را متوقف کند، محدودیت باتری اعمال کند یا اجازهٔ اتصال را پس بگیرد. هیچ تضمینی برای اتصال همیشگی یا ناشناس‌ماندن وجود ندارد.

## ساختار و آزمون

- `agent/`: عامل رانر، مدیریت کشور، رله‌ها و رمزگذاری اطلاعات نشست. رفتار پیش‌فرض VLESS برای کلاینت اصلی حفظ شده؛ workflow جدید اندروید VMess را انتخاب می‌کند.
- `android/`: اپ، رابط کاربری و سرویس `VpnService`، ورود OAuth، مدیریت و لغو runها و دریافت کتابخانه‌های بومی.
- `.github/workflows/github-vpn-session.yml`: اجرای یک نشست آزمایشی؛ `.github/workflows/build-android.yml`: آزمون و ساخت APK.
- `tests/agent.test.mjs` و `android/app/src/test/`: آزمون تنظیمات عامل، رمزنگاری سازگار بین کلاینت و سرور، اعتبارسنجی رله و انتخاب کشور.

اجرای آزمون‌های Node بدون نصب وابستگی:

```bash
node --test tests/*.test.mjs
```

مجوزهای کتابخانه‌های استفاده‌شده در `android/app/src/main/assets/licenses/` همراه APK بسته‌بندی می‌شوند.
